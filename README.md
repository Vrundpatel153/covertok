# CoverTok — Luxury Mobile Covers & Accessories E-Commerce Experience

A modern, high-performance, and visually stunning mobile cover and tech accessory web store built in **pure vanilla HTML5, CSS3, and JavaScript**.

## Key Highlights

- **4-Banner Interactive Hero Showcase**: Signature Wave Swirls, Diamond 9H Tempered Glass, Shockproof MagSafe Armor, and Artisan Bohemian Prints with dynamic bottom toolbar navigation.
- **Go Ultra. Go Frameless.**: Interactive 3D perspective trio of ultra-thin frameless cases with floating camera bezels, wishlist toggling, and live social proof notifications.
- **Build Your Own Combo**: Interactive 3-in-1 accessory bundle builder with real-time discount unlocks (Grab Any 3 for ₹1199 / $14.00).
- **Shop Our Collections**: 4 category showcases for iPhone Covers, AirPod Covers, iWatch Bands, and MagSafe Accessories with filter tabs.
- **Dedicated Product Configurator (`product.html`)**:
  - Full iPhone model selector (iPhone 16 Pro Max, 16 Pro, 16, 15 series, 14 series, 13 series, 12 series) with real-time stock indicator.
  - Multi-color swatches with live image and color title updates.
  - Case finish & protection options (Frameless Bumper, 9H Diamond Glass, MagSafe Impact Armor).
  - Complete accessory add-on options (Lens protectors, MagSafe card wallet, 60W cable, AirPods case, Watch sport band) with live total price calculator.
  - Slide-out cart drawer, sticky purchase bar, and express checkout modal.

## Architecture

- **Vanilla HTML5**: Semantic, accessible markup.
- **Vanilla CSS3**: Fluid `clamp()` typography, CSS variables, glassmorphism, responsive grid layouts.
- **Vanilla JavaScript (ES6+)**: Zero external dependencies, modular state management.
